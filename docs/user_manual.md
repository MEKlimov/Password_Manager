# Руководство пользователя и инструкции по сборке

## [cite_start]1. Инструкции по сборке [cite: 117]
[cite_start]Проект написан на Java с использованием графической библиотеки JavaFX и системы сборки Maven[cite: 42].

**Системные требования:**
* JDK 17 или выше.
* Apache Maven (рекомендуется версия 3.8+).
* Операционная система: Windows, macOS (вкл. Apple Silicon), Linux.

**Сборка и запуск:**
1. Откройте терминал и перейдите в корневую папку проекта (где находится файл `pom.xml`).
2. Для загрузки зависимостей, компиляции кода и запуска приложения выполните команду:
   ```bash
   mvn clean compile javafx:run
